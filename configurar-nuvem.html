Enquanto a nuvem não estiver configurada no arquivo firebase-config.js, o site continua funcionando só no aparelho (como hoje).

1) Enviar e receber da nuvem

Enviar: sobe o que está neste aparelho (só grava se for mais novo que o da nuvem — não apaga alteração do outro aparelho).
Baixar: traz da nuvem para este aparelho (use no PC depois de alterar no celular, e vice-versa).

2) Baixar planilhas da nuvem (CSV)

O admin/gestor baixa de qualquer aparelho o que já foi sincronizado na nuvem.

3) Movimentação dos membros (log)

Logins, fotos, cadastros, alterações de perfil e relatórios de células (presença/ofertas) registrados na nuvem.

Como ativar a nuvem (uma vez)

  1. Acesse console.firebase.google.com
  2. Crie um projeto (ex.: ibn-diamantino)
  3. Em “Build” → Firestore Database → criar banco (modo produção)
  4. Regras do Firestore (temporárias para a igreja começar):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
  1. Configurações do projeto → Seus apps → Web → registrar app
  2. Copie apiKey, authDomain, projectId, etc.
  3. Cole no arquivo firebase-config.js do site (no lugar de COLE_AQUI)
  4. Publique o site no GitHub de novo

Depois de estabilizar, peça a um técnico para restringir as regras (só admin autenticado).
